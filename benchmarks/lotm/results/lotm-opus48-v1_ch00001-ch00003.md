# LOTM benchmark results: run `lotm-opus48-v1`, chapters 1-3

Derived, methodology-safe summary. No source text, reference translations, or generated chapter
prose appear here; only condition labels, scores, deterministic outcomes, and short terminology
examples. Corpus and outputs stay local and git-ignored.

## Run metadata

| Field | Value |
|---|---|
| Run ID | `lotm-opus48-v1` |
| Backend | `claude_code_stateless` (subscription-backed, one fresh `claude -p` per candidate) |
| Model | `claude-opus-4-8` (no thinking configuration) |
| Mode | `independent` (each condition keeps its own translation history) |
| Chapters | 1-3 (of a planned 10; benchmark paused after ch3) |

Conditions (see [benchmarks/README.md](../../README.md)): **A** = chapter-only; **B** = A + a rolling
window of that condition's own prior translations; **C** = B + chapter-bounded canonical context and
translation memory (full Wenmai). All three share the same model, settings, prompt assembler, and
style guide; only the included context differs. Scoring was blind (candidates presented as 1/2/3
with the label->condition map withheld until after scoring). Human scores are 1-5 (5 = best);
`hallucination_or_embellishment` uses 5 = no unsupported additions. Deterministic `fmt` = automated
formatting validity (front matter + single H1).

## Deterministic formatting

Formatting validity was independent of condition: the code-fence wrapping that invalidates a
candidate appeared on different conditions each chapter (ch1: A invalid; ch2: A and B invalid; ch3:
B and C invalid). It is a per-process output-formatting artifact of the current stateless CLI
backend, caught automatically, and deliberately left uncorrected so it remains a visible outcome.
It does not track translation quality (in ch3 the two highest-scored candidates were both flagged).

## Compact C / B / A comparison (informative chapters)

| Dimension | Chapter | A | B | C |
|---|---|:---:|:---:|:---:|
| contextual_correctness | 2 | 3 | 4 | 5 |
| contextual_correctness | 3 | 3 | 4 | 5 |
| terminology_consistency | 2 | 4 | 5 | 5 |
| terminology_consistency | 3 | 3 | 4 | 5 |

On both informative chapters, adding a rolling window (B) improved contextual correctness and
terminology consistency over chapter-only (A), and adding chapter-bounded structured memory (C)
improved them further, with C the only condition scoring the maximum on both in both chapters. The
gap was widest at chapter 3, where the chapter-only condition drifted on established renderings
(for example the frozen `Kingdom of Loen` and `fortune-changing ritual`) while the full-Wenmai
condition preserved them.

## Headline

Chapters 2 and 3, the two informative chapters, both ranked **C > B > A**.

## Disclaimer

**Two informative chapters are not enough to draw a performance conclusion.** This is a directional
early signal from a single run, single model, single evaluator, N = 2 informative chapters, with no
statistical power. The benchmark is designed so that a null or reversed B-vs-C result at larger N
would be a legitimate and useful finding; nothing here should be read as establishing that
structured memory outperforms a rolling window in general.

## Proposal audit (context-extraction, post-evaluation state)

Extraction proposals were reviewed by a human before any merge. Leakage here means claims not
grounded in the chapters seen so far (a risk with a pretrained model translating a known work).

- **Chapter 1:** no proposal leakage observed.
- **Chapter 2:** one explicit future-story / latent-pretraining claim was caught and rejected in
  human review (language asserting connections to the work's "later mystical systems" for a
  chapter-2 term). It was excluded from canonical state; the chapter-2 translation itself did not
  contain this leakage, so the frozen translation evaluation is unaffected.
- **Chapter 3:** the seven orthodox deities in the proposal were verified as **source-grounded**
  (chapter 3 lists all seven explicitly), not leakage. The proposal did, however, contain
  unsupported inference and over-generalization: a standalone `Backlund` location inferred from
  "Backlund University", and two phrases asserted to be "recurring" on a single observed occurrence.
  These were rejected or deferred in human review.
- **Chapter 3 status:** human review is complete, but canonical chapter-3 state has **not** been
  merged at this checkpoint. The benchmark is paused after chapter 3.
